Executive Overview

Irisjev Wooden Crafts is a high-ticket specialized luxury e-commerce platform engineered to sell master-carved Hindu deity sculptures, temple panels, and bespoke woodcraft commissions. The business operates in the premium artisanal segment (avg. order value ₹1,40,000–₹3,50,000), requiring distinct workflows that generic platforms cannot handle:

🛡️ Dual-Session Auth Isolation

Customer OAuth sessions (irisjev_customer_auth_token) are fully isolated from Admin sessions (irisjev_admin_auth_token) using separate Supabase client instances to prevent session collisions.

📦 Fragile Sacred Cargo Logistics

Automated generation of legally compliant thermal A4/A5/4×6 inch packing slips with barcodes, QR parcel tracking, and mandatory "FRAGILE – SACRED WOODEN ARTIFACT" warning banners required by courier insurers.

⚡ Edge Function Payments

3 Supabase Deno Edge Functions handle the complete Razorpay lifecycle: razorpay-create-order, razorpay-verify-payment, razorpay-webhook. HMAC-SHA256 cryptographic signature validation prevents payment tampering.

Admin Login & Secure Access

Route: /admin/login — Protected. Any unauthenticated visit to /admin/* redirects here automatically.

Authentication Methods

Method A: Email + Password
  1. Open /admin/login
  2. Enter your admin email address (e.g. admin@irisjev.com)
  3. Enter your password in the lock-icon field
  4. Click "Sign In with Password" (black button)
  5. On success → redirected to /admin Dashboard
Method B: Google OAuth
  1. Click "Sign in with Google" (white button)
  2. Google popup opens → choose authorized Google account
  3. Redirects to /admin with session established
  4. Session persists in irisjev_admin_auth_token (localStorage)
Security Note: Admin and customer sessions use completely separate Supabase client instances. A customer logging out on the storefront will never invalidate your admin session, and vice versa.

Step 2 — Add or Edit a Sculpture (Modal Form)

Click "+ Add Masterpiece" (new) or the pencil icon (edit). The modal has a dark header bar with the form title and X close button.

SCULPTURE TITLE *

Free text. e.g. "Dancing Nataraja in Aged Teak Wood". Required.

CATEGORY * (Dropdown)

Options: God Sculptures · Wall Mounts · Square Panels · Grand Sculptures · Temple Doors · Custom Commissions · Baskets & Bottles · Mirrors & Decor

PRICE (INR ₹) *

Number only (e.g. 185000). System auto-computes USD: Math.round(priceINR / 83.33)

PRODUCT GALLERY * (Images)

Two modes via radio button:

  • Image URL — paste any public CDN/image URL then click "Add"
  • Upload Image — pick JPG/PNG/WebP/AVIF file. Max 230KB. Uploads to Supabase bucket product_images/products/{random}.{ext}

First image in the gallery becomes the primary thumbnail (products.image). All others saved to products.gallery_images[].

MATERIAL / TIMBER

Default: "Aged Teak Wood". Other options: "Country Rosewood", "Sandalwood". Stored in products.material. Also populates timber_options[].

DIMENSIONS

Default: 18" H x 12" W x 8" D. Freetext, stored in products.dimensions.

DESCRIPTION

3-row textarea. Describe craftsmanship, iconography, and finish. Stored in products.description.

✓ Save Changes / Publish Product

The full-width black button submits the form. On success, the modal closes and the product table auto-refreshes from Supabase. For new products, ID is generated as prod-{Date.now()}.

⚠ Delete Sculpture

Click the red Trash icon in the table. A browser confirm() dialog appears: "Are you sure you want to delete {name}?". On confirm, supabase.from('products').delete().eq('id', id) runs.

Backend Verification — Check Product Was Saved

Go to Supabase Dashboard → SQL Editor and run:

SELECT id, name, category, price_inr, price_usd, material, dimensions, array_length(gallery_images, 1) AS image_count, updated_at FROM products ORDER BY updated_at DESC LIMIT 5;

Or view in Table Editor: Supabase → Table Editor → products and verify all columns match the form inputs.

Orders & Dispatch Center

Route: /admin/orders — Component: OrdersManager.tsx — Supabase: orders JOIN customers

Orders & Dispatch Center — searchable, filterable, with per-row action icons for view, dispatch, print, and invoice

Filter & Search Controls
  • Search field: order number, customer name, AWB, Razorpay payment ID
  • Status pills: All Paid COD Pending Processing Shipped Delivered
Action Icons Per Row
  • Eye — View full order detail modal (OrderModal)
  • Truck/Edit — Open courier tracking update: enter AWB, courier name, estimated delivery. AWB auto-generates for Delhivery, BlueDart, FedEx, DTDC, DHL, IndiaPost, Xpressbees
  • Printer — Print shipping label slip (opens ShippingLabelSlip)
  • FileText — Print customer invoice
How to Dispatch an Order (Step-by-Step)
  1. Find the order by searching the order number or customer name
  2. Click the Truck/Edit icon on that row
  3. In the tracking update panel, choose courier from: Delhivery Express, BlueDart Surface & Air, FedEx Priority, DTDC Express, DHL Express Worldwide, India Post Speed Post, Xpressbees Logistics
  4. AWB (tracking number) auto-generates — or enter a manual AWB if you already have one from the courier
  5. Set status to Shipped / Dispatched and set estimated delivery date
  6. Click "Update Tracking" — this: (a) updates orders row with courier, tracking_number, tracking_url; (b) dispatches order.shipped webhook event; (c) sends AWB dispatch email to customer via Resend
Bulk Update (Multiple Orders at Once)

Check multiple order checkboxes → click "Bulk Update Selected" button (top right). The bulk modal has two tabs:

  • Manual Tab: Per-order rows, individually set courier + AWB + status
  • Quick Apply Tab: Set same courier, auto-generate AWBs, same status for all selected orders in one click. Milestone fields: title, description, location (e.g. "Chennai Central Logistics Center, TN")
