Executive Overview

Swarna Wooden Crafts is engineered to serve the high-ticket luxury artisanal segment. It caters to art collectors, interior designers, temple trusts, and global importers seeking certified teakwood, rosewood, and sandalwood master carvings.

🛡️ Dual Session Isolation

Customer storefront sessions (irisjev_customer_auth_token) and admin sessions (irisjev_admin_auth_token) use isolated Supabase storage keys to eliminate credential collisions.

📦 Automated Logistics & Labels

Automated thermal shipping label generator producing printable dispatch slips with QR codes, barcode tracking, and insurance fragility warnings.

⚡ Real-Time Multi-Currency

Dynamic dual currency calculations supporting live switching between Indian Rupee (**INR ₹**) and US Dollar (**USD $**) across catalogue, cart, and checkout.

Database Schema & Supabase SQL

Database Setup: Execute the SQL migration below in your Supabase SQL Editor.
-- 1. PRODUCTS TABLE CREATE TABLE IF NOT EXISTS products ( id TEXT PRIMARY KEY, name TEXT NOT NULL, category TEXT NOT NULL, price_inr NUMERIC NOT NULL, price_usd NUMERIC, image TEXT NOT NULL, gallery_images TEXT[] DEFAULT '{}', description TEXT, dimensions TEXT DEFAULT '18" H x 12" W x 8" D', material TEXT DEFAULT 'Aged Teak Wood', timber_options TEXT[] DEFAULT '{Aged Teak Wood,Country Rosewood,Sandalwood}', rating NUMERIC DEFAULT 5.0, is_best_seller BOOLEAN DEFAULT false, created_at TIMESTAMPTZ DEFAULT now() ); -- 2. ORDERS TABLE CREATE TABLE IF NOT EXISTS orders ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), order_number TEXT UNIQUE NOT NULL, customer_id UUID REFERENCES customers(id), total_amount NUMERIC NOT NULL, currency TEXT DEFAULT 'INR', status TEXT DEFAULT 'pending', payment_method TEXT DEFAULT 'prepaid', shipping_address JSONB NOT NULL, tracking_number TEXT, created_at TIMESTAMPTZ DEFAULT now() ); -- 3. COUPONS TABLE CREATE TABLE IF NOT EXISTS coupons ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), code TEXT UNIQUE NOT NULL, discount_type TEXT NOT NULL, discount_value NUMERIC NOT NULL, min_cart_amount NUMERIC DEFAULT 0, expiry_date TIMESTAMPTZ, is_active BOOLEAN DEFAULT true );
